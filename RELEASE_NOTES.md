# NOIR Launcher v0.1.0 — Initial Release

Welcome to the initial public release of **NOIR Launcher** (`v0.1.0`, `versionCode: 1`).

NOIR is an exceptionally clean, editorial Android home launcher inspired by Swiss typography, tactile paper textures, and graphite aesthetics.

---

### Highlights & Features

1. **Native Android HOME Integration**
   - Official `CATEGORY_HOME` and `CATEGORY_DEFAULT` support.
   - Android 10+ `RoleManager.ROLE_HOME` dialog integration.
   - Dynamic default launcher status checking and dedicated configuration in Preferences.

2. **Curved Alphabet Navigation Scrubber**
   - Smooth vertical scrubbing along the right screen edge.
   - Mathematical Gaussian arc deflection with active letter magnification.
   - 52dp floating letter preview badge with tactile haptic feedback.

3. **Swiss Editorial Aesthetics**
   - Warm natural paper background (`#F2F0E9`) in light mode.
   - Deep charcoal background (`#151515`) in dark mode.
   - Editorial serif headlines (`EditorialSerif`) and crisp sans-serif indices (`SwissSans`).
   - Dynamic system bar contrast ensuring seamless edge-to-edge immersion.

4. **Advanced Icon Personalization**
   - 5 Geometries: Original, Circle, Rounded Square, Square, Squircle.
   - 3 Color Modes: Original Colors, Theme-Matched Monochrome, and Custom Tint.
   - Granular size scaling (24–56dp) with live real-time preview.

5. **Sorting & Filtering**
   - Instant search across installed applications.
   - Alphabetical A–Z, Alphabetical Z–A, Recently Installed, and Recently Used sorting.
   - Live package broadcast receiver tracking app installations and removals.
